# 设计决策

## 2026-10-29：采用三模块结构

使用 `core`、`script`、`plugin`，避免模块名重复 `spectrum-` 前缀。这样可以直接表达模块职责，也方便未来发布独立的脚本编译器和运行时测试工具。

## 2026-10-29：使用 TabooLib 进行平台适配

项目不把某个 Paper 版本当作最终支持范围。通用功能使用 TabooLib，NMS 功能集中在平台适配层，并通过代理隔离版本差异。

## 2026-10-29：先使用 Typed IR，再考虑字节码

第一版脚本编译结果是受控的内部指令和 Typed IR，由运行时解释执行。这样便于测试、调试、限制预算和实现技能取消。

## 2026-11-09：运行时由游戏 tick 驱动

技能运行时不创建阻塞线程。`wait` 保存恢复 tick，`SkillScheduler` 在下一次驱动时继续执行。Minecraft 动作通过显式注册表注入，保持脚本模块与服务器 API 隔离。

## 2026-11-09：发行 JAR 不内置 Kotlin 标准库

插件模块使用 `compileOnly` 编译 Kotlin，并只合并 `core` 与 `script` 的类目录。TabooLib 的版本描述文件保留 Kotlin 版本，让运行时依赖解析继续工作；构建阶段不把 Kotlin 标准库复制进插件 JAR。

## 2026-11-09：阶段、掉落和模型采用声明式扩展

Boss 阶段、掉落和模型绑定都放在怪物 YAML 中。阶段只允许通过阈值、属性覆盖和已注册技能改变运行时行为；掉落概率计算保持在无服务器依赖的 `core`；模型和其他外部插件通过 `MobIntegration` 注册表接入，避免在主项目中加入具体插件依赖和大量兼容层。

## 2026-11-09：技能反馈使用原生 Legacy 文本

消息、Title、ActionBar 和声音动作由插件层通过 Bukkit/TabooLib 原生接口执行。文本只支持 `&` 和 `§` 颜色码，脚本运行时不引入 MiniMessage 解析器；插值只负责把受控运行时值转换为文本。

## 2026-11-10：插件消息统一使用 TabooLib I18n

命令反馈、生命周期日志、配置诊断和 Script 编译诊断由插件层通过 TabooLib I18n 输出。`core` 和 `script` 不依赖 TabooLib，只产生英文错误正文；这样既保持模块边界，也能让语言文件统一控制消息格式。技能消息动作可以使用 `i18n:节点名` 引用语言节点，同时保留 `&`/`§` 原生文本兼容旧技能。

## 2026-11-10：方块投射物使用受控 FallingBlock

`mechanic.projectile.launch` 使用带 PDC 标记的 `FallingBlock` 表示方块外观，插件 Tick 服务负责射线、实体命中、伤害和生命周期。这样脚本不会直接创建任意实体，也能在投射物命中后统一清理并排除施法者。

## 2026-11-10：技能 API 使用统一注册表，不保留旧语法

目标选择、实体条件与 Mechanics 分别使用 `targeter`、`condition`、`mechanic` 命名空间。旧顶层服务、`damage`/`ignite` 和实体条件成员全部移除。辅助状态、随机、技能调用与受控命令服务保留其独立职责。

签名由 `ScriptApiRegistry` 定义，`ScriptApiBindings` 校验并发布完整实现快照，避免编译器与运行时名单分叉。扩展只能追加，活动技能保留旧绑定。范围查询使用球形距离、UUID 去重、距离排序和统一返回上限；泛型随机选择保持玩家类型。

查询返回数据快照，已保存位置和列表不会自动改变。Condition 以及新的 Targeter 调用通过平台解析器读取当前实体状态；Mechanic 通过身份解析实体并拒绝失效对象。这样等待前后的目标选择、位置预警与实体生命周期都有明确语义。

## 2026-11-10：施法策略属于技能，资源属于执行作用域

施法组、并发策略、阶段取消和取消清理只在 `.sms` 中声明。冷却使用完整资源 ID。子技能必须显式传入目标，默认取消联动，并始终继承根调用深度。

程序任务与资源作用域分开：正常完成不删除仍在飞行的投射物或仍显示的临时血条，作用域保留到资源和联动后代全部释放。取消或失败则按策略清理；实体、世界生命周期和插件关闭强制回收。活动作用域共用现有实例预算，避免新增无界缓存。
